Architecture layers

What the customer sees vs. what the gateway manages
# Layer Purpose Current prototype
01 Customer system Application, backend service, or agent. Browser demo and curl client.
02 One API A standard OpenAI-compatible request format. /v1/chat/completions
03 Entry control Customer API key, request limit, and logs. dev-gateway-key plus in-memory limit.
04 Model control Public model names, route rules, and future fallback. smart-fast maps to qwen-plus.
05 Provider adapter Convert the gateway request to provider format. DashScope OpenAI-compatible adapter.
06 Model provider The real upstream AI model service. Alibaba Cloud Model Studio / Qwen.
